# 姉妹サイト向け: `/api/latest` の `snapshot` 仕様

ポータル（hub-game.com）のトップに「2タイトルの最新データ」表がある。
各サイトが `/api/latest` で返す `snapshot` を読んで、掲載数とパッチ情報を出す。

**Honor of Kings は対応済み。Wild Rift は未対応。** 未対応の列はポータルが持つ
静的値で出していて、更新はポータル側の手作業になっている。`snapshot` を足せば
自動で切り替わり、ポータルは何も変更しなくてよい。

実装の参考: `https://hok.hub-game.com/api/latest` を叩けば、動いている実物が見られる。

---

## 1. 何を足すのか

`/api/latest` は既に 200 を返している。返している JSON に `snapshot` キーを1つ足すだけ。
既存のキー（`site` / `path` / `version` / `date` / `ja` / `en`）は変えないこと。
ポータルの「今週の注目」カードがそれを使っている。

```jsonc
{
  "site": "wildrift",
  "path": "/patches",
  "version": "7.2d",
  "date": "2026-08-26T12:00:00+00:00",
  "ja": { "title": "…", "body": "…" },
  "en": { "title": "…", "body": "…" },

  // ↓ ここから下が追加ぶん
  "snapshot": {
    "patch": {
      "label":   "Patch 7.2d",
      "labelJa": "パッチ7.2d",
      "date":    "2026-08-26",
      "changedHeroes": 15
    },
    "catalog": {
      "heroes": 141,
      "items":  167,
      "spells": 9,
      "arcana": 53
    }
  }
}
```

## 2. 各項目の意味と条件

ポータル側の検査（`src/lib/sisterSites.ts` の `toSnapshot`）が全項目を型まで見る。

### `snapshot.patch`

| キー | 型・条件 | 意味 |
|---|---|---|
| `label` | 空でない文字列 | 版名の英語表記。例 `Patch 7.2d` |
| `labelJa` | 空でない文字列 | 版名の日本語表記。例 `パッチ7.2d` |
| `date` | 日付として解釈できる文字列 | その版の公開日 |
| `changedHeroes` | **0以上**の整数 | その版で調整されたチャンピオン数 |

`changedHeroes` だけ 0 を正しい値として通す。不具合修正だけの版があるため。

### `snapshot.catalog`

| キー | 型・条件 | Wild Rift では |
|---|---|---|
| `heroes` | **1以上**の整数 | チャンピオンの掲載数 |
| `items` | 1以上の整数 | 装備の掲載数 |
| `spells` | 1以上の整数 | サモナースペルの掲載数 |
| `arcana` | 1以上の整数 | **ルーンの掲載数を入れる** |

`arcana` にルーン数を入れるのは、2タイトルで形を共通にしているため。
表示側が「ルーン◯種」と出し分けるので、キー名は気にしなくてよい。

## 3. 落ちる条件

**1つでも欠けるか型が違えば、その列は静的値のまま出る。** 表は消えない。
半端な数字が混ざった行を出さないための作りなので、部分的に返すことはできない。

よくある取りこぼし:

- **数値を文字列で返す。** `"141"` は通らない。JSON の数値で返すこと
- **小数。** `Number.isInteger` を通らない
- **0 を返す。** `catalog` の4つは1以上。0件の一覧は表に出す意味がないため弾いている
- **`date` のタイムゾーン。** ポータルは `new Date(date).toISOString().slice(0, 10)` で
  日付部分を取る。`2026-08-26T00:30:00+09:00` のような値だと UTC で前日に回り、
  表示が1日ずれる。**`2026-08-26` の形で返すのが安全**

## 4. 数値は数え直して返すこと

`catalog` の4つを定数で書かない。掲載データ（チャンピオン一覧の JSON など）の
件数をその場で数えて返す。そうしておくと、データを足したときに表の数字が
勝手に追従する。定数だと、更新のたびに2箇所直すことになり、いずれ食い違う。

Honor of Kings 側は `hok_heroes.json` などの `.length` をそのまま返している。

## 5. キャッシュ

ポータルは 1800 秒（30分）でキャッシュして取りに行く。返す側も同じ間隔にしておくと
挙動が読みやすい。Next.js なら Route Handler に次を置く。

```ts
export const revalidate = 1800;
```

## 6. 確かめ方

```bash
curl -s https://wildrift.hub-game.com/api/latest | jq .snapshot
```

`snapshot` が上の形で返っていれば、ポータル側は次のデプロイまたは再生成で
自動的に取り込みへ切り替わる。切り替わると、表の下の注記から
「Wild Rift の掲載数は◯◯時点」の一文が消える。これが切り替わりの目印になる。

`jq` が無ければ `| grep -o '"snapshot".*'` でもよい。

---

## 補足: なぜこの形なのか

ポータルは相手のデータ源（リポジトリ内の JSON なのか DB なのか）を知らずに済ませたい。
そのため各サイトが整形済みの JSON を返し、ポータルはそれだけを読む。
将来どちらかがデータ源を替えても、返す形さえ保てば相手側は影響を受けない。

表に出す数字は、いつ時点で・どこから来たかを説明できるものだけにしている。
説明できない数字は載せない方針なので、取り込めない列には「◯◯時点」と
明示して静的値を出している。
