### 申請の時期

決めるのは運営者。HoK のセッションからは、Search Console の hub-game.com で `/hok/`・`/mlbb/`・`/wildrift/` の URL が
「登録済み」に出始めてから押すよう勧めた。Google のサイト移転の説明に
「中規模のウェブサイトの場合は、Google が古い URL の代わりに新しい URL を段階的に表示し始めるまでに数週間以上かかることがあります」
とあるため（https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes?hl=ja 、2026-09-29 に確認）。
これは検索の話で、AdSense の審査が移転に左右されるかは、公式の記述が見つからず未確認。
