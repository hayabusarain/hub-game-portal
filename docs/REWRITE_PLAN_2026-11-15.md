# ヒーロー解説の書き直しの設計（2026-11-15、運営者の判断待ち）

運営者の指示（11/15）: 外部の文章分析を受けて全ページの文章を書き直すなら、HoK のキャラ解説（序盤・中盤・終盤・集団戦）をモバレと同じ形にする。あわせて、AdSense の審査に通りやすくなる書き直し方を考える。
根拠は `docs/ADSENSE_PASS_PLAN_2026-11-07.md`（調査8本と反証）と、`docs/ADSENSE_REVIEW_LOG.md` の 11/14・11/15 の節。

## 何のための書き直しか

3回の不承認すべてにあって今も残る要因は、公式アイコンの再掲、AI が一度に書いた解説、サイトの若さの3つ。書き直しが手を入れられるのは2つ目だけ。
AI がもう一度まとめて書くだけでは、「AI が一度に書いた解説」が新しくなるにすぎない。次の5つを満たす形にして、はじめて審査に効く向きになる。

## 審査に効かせる5つの決まり

1. **同じ事実を1ページに2回書かない**（AdSense ヘルプ answer/10015918「同じ文を複数のページに置かない」「似たページは充実させるか統合する」）
   - HoK の立ち回りに出る単位つきの数値は、93% が同じページのスキル説明にもある（10/31 の分析）。立ち回りでは数値を写さず、その数値が試合の中で何を意味するかだけを書く
   - HoK は4節（序盤・中盤・終盤・集団戦）を、モバレと同じ3節（序盤・中盤以降・集団戦）にする。今は4節とも中央値が215〜225字で、長さまで型になっている。書くことが少ない節は短くてよい
2. **型と機械らしさを消す**
   - 1つの欄の中で敬体と常体を混ぜない（今はモバレの戦術ガイドで94%、HoK のビルド解説で99%が混在）。解説は敬体にそろえる
   - ぶつ切りの短文は、理由や条件でつなぐ（モバレの戦術ガイドは25字以下の文が41%）
   - 書き出しと段の組み立てを、ヒーローごとに変える。「絶対」「鉄則」「正解」「一瞬で」などの誇張は使わない（HoK の立ち回りに計121か所）
   - HoK のビルド解説は、合計値の引き算を並べる形をやめ、「どの装備がそろうと何ができるか」を、装備の効果文にある範囲で書く。「○○Gで立つ」は使わない
3. **事実は足さない**（共通ルール3、スパムポリシーの「付加価値の無い生成 AI の量産」）
   - 根拠にできるのは、今までどおりスキル本文・装備の効果文・公式の統計・パッチノートだけ。プレイした感覚を AI が想像で書かない。外部の分析の改善案には、データに無い事実（バイロンの調整内容など）が入っていたので採らない
   - 数値は監査で照らし合わせる（モバレは検査22、HoK は同じ検査を足す）
4. **人の手を本物にする**（publisherpolicies/11112688「手動のレビューやキュレーションの無い自動生成の画面」）
   - 運営者が、試しの10体と、流入上位のヒーローを自分で読む。違和感のある文を直すか、直す指示を出す。読んだ体数と日付を記録し、about の作り方の節（B1）に「運営者が読んで確かめた範囲」として実態どおりに書く
   - 運営者の実感は、ヒーロー別でなくレーン別・ロール別に5〜6個もらう（使っているヒーローを出さずに書ける）。置き場所は、固有の文が少ないロール別・レーン別のページ（モバレのファイターとメイジは、今も共通の文が85%以上）
5. **出し方で損をしない**
   - ヒーロー別の更新日を先に作る（今は1体直すと全ヒーローの更新日が動く）。直したヒーローだけ日付が変わるようにする
   - 流入の多いヒーローから、2〜3回に分けて出す。各回のあと、Search Console でヒーロー詳細のクリックを見る（28日で706クリック。Tier 表には触らないので、流入の大半は影響を受けない）
   - HoK の英語版も同じ3節にそろえる（日英同時。英語版は表示が月1.5万回あり、言語を指定しないクローラーの入口でもある）
   - 申請は、最後の回の push の翌日から14日あける

## 段取り

1. 共通ルール4の「3文に1回は常体や体言止めを混ぜる」を「1つの欄の中で敬体と常体を混ぜない」に直す（正本 `Desktop/hub-game-rules/shared/AGENTS.shared.md`、`node sync.mjs` で3リポジトリへ）。両サイトの監査に、混在を止める検査を足す
2. 両サイト5体ずつ、流入の多いヒーローで試しに書き直す。前後を並べて運営者に見せる。HoK は3節の形で出す。ここで書き方を固める
3. 運営者がよしとしたら、残りを展開する。モバレ133体（戦術ガイド・相性の理由・ビルド解説）、HoK 120体（立ち回り・ビルド解説、日英）。サブエージェントの本数は、始める前に出して承認を取る
4. 出すたびに本番を確かめ、指標を測り直す。about の作り方の節（B1）を同じ時期に出す

## やらないこと

- Tier 表の上部とタイトルは触らない
- プレイ歴や実戦の感想を作らない。運営者から出たものだけを書く
- 一度に全ページを差し替えて、日付だけ新しく見せることはしない（中身を変えたヒーローだけ更新日を上げる）
- スキル本文（ゲーム内の表示の書き起こし）は書き直さない。対象は当サイトが書いた解説だけ
